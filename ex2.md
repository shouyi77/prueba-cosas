#Installation
Follow these steps to prepare the project:
1. Create a virtual environment:
   - macOS/Linux: `python -m venv .venv`
   - Windows: `py -m venv .venv`
1. Activate the environment.
1. Install the packages with `pip install -r requirements.txt`.

## Verify the installation
Run this command:
```
python -c "import torch; print(torch.__version__)"
```
For troubleshooting, see the [PyTorch installation guide](https://python.org/get-started/locally/).
