# Image Classifier
A lightweight application that uses a **convolutional neural network (CNN)** to
classify images into *three categories*.

## Features
- Supports **.jpg** and **.png** files
- Returns a label and a confidence score
- Example: run `pyhton predict.py --image cat.png`
## Data
1. Place images in data/input/.
1. Follow the [dataset preparation instructions](docs/data.md).
